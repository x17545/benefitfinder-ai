# 로컬 데이터

`data/` 아래는 이 안내 문서만 공유하고 나머지는 기본적으로 Git에서 제외한다. 다음 경로는 실제 수집·처리 시 로컬에 생성한다. 새 이름으로 저장한 내보내기 파일도 제외되도록 `raw/`·`processed/`·`indexes/` 세 경로만 나열하는 방식 대신 기본 제외를 적용한다.

| 경로 | 내용 |
|---|---|
| `raw/` | 수집 원본과 수집 기록 |
| `processed/` | 정규화·검증 결과 |
| `indexes/` | 재생성 가능한 검색 인덱스 |

- 공용 가상 예제는 `contracts/fixtures/`에 둔다. 실제 공고나 사용자 데이터로 교체하지 않는다.
- 실제 데이터 공유는 접근 권한과 저장 위치를 정한 후 진행한다. 원본을 PR에 첨부하지 않는다.
- 수집 원본은 출처·수집 시점·문서 버전을 보존하고 정제 결과와 구분한다.
- 원천 응답 구조를 `contracts/v1/benefit.schema.json`으로 변환하는 코드는 `backend/src/benefitfinder/ingestion/`에 둔다.
- API 키, 개인정보와 개인 대화는 이 디렉터리와 Git에 저장하지 않는다.
