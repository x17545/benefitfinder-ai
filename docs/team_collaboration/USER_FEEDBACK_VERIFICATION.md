## 3. 미반영 및 후속 개선 사항

- 개별 정책 신청 화면으로 직접 연결: 미구현
- 미충족 정책 목록의 추가 필터 및 페이지 분할: 검증되지 않음
- 상황 변화 실제 오류 안내: 운영 환경 재현 미실시
- 사용량 초과 안내: 코드 확인, 운영 환경 재현 미실시
- 기타 개선 의견: 총 31건 모두 반영 상태와 검토 근거를 [USER_TEST.md](../product/USER_TEST.md) 6장에 기록 완료. 일부는 원인 미확인 또는 향후 검토 과제로 남음

- 장학금·체험 프로그램 확대 (29번 T4): 현재 취업·주거 중심 MVP 범위이며 별도 추천 기능은 미확인
- 기업·민간 지원금 추가 (30번 T22): 별도 데이터 수집 및 추천 기능은 미확인
- 향후 받을 수 있는 정책 예측 (31번 T24): 미래 자격 취득 시점과 정책 예측 기능은 미확인
미반영 및 향후 검토 항목은 확인된 MVP 범위와 구현·검증 결과를 근거로 기록했다. 시간 부족이나 기술적 어려움 등 담당자가 확인하지 않은 사유는 추정하여 기재하지 않았다.
