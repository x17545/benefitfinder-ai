## 실행 개요

| 항목 | 내용 |
|---|---|
| 실행 위치 | Render cron `benefitfinder-daily-refresh` (일회성 Command로 실행 후 원래 명령으로 복원) |
| 배포 커밋 | `cf1334f` (PR #95 머지) |
| 미리보기(읽기 전용) | 01:37 KST: 대상 14건, 변경 12건, 건너뜀 0건 |
| 반영 실행 | 01:45:08 시작, 01:45:17 완료 (KST) |
| 단계별 결과 | 묶음 생성 12건 → 검증 `{"action":"validate","count":12}` → 철회 `{"action":"retire-exact","count":12}` → 재게시 `{"action":"publish","count":12}` → `DONE` |
| 복구 단계 | 재게시가 실패하면 철회본을 자동 복원하도록 넣었으나, 실패가 없어 실행되지 않음 |
| Command 복원 | `uv run --locked --no-sync python -m benefitfinder.jobs refresh-data --data-dir data --notify-discord` (화면에서 확인) |
