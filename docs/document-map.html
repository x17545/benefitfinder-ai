정책을 준비하는 흐름

  1. 공식 자료 수집

    공식 API와 공고·지침을 읽고 원문과 버전을 보존합니다.

    • 정책 데이터 준비 설계
    • F08 갱신 실행과 운영 확인

  2. 후보 추출과 검수

    AI Agent가 자격·금액·중복 제한 후보와 원문을 찾고, 사람이 근거와 예외를 확인합니다.

    • F12 공식 문서 분석
    • 검수와 게시 기준

  3. 승인 자료 게시

    승인된 정책·계산 규칙·근거를 같은 버전으로 게시합니다.

    • 승인 자료의 게시 절차
    • 현금 정책 카탈로그

사용자가 결과를 보는 흐름

조건 입력 · 코드 계산 · 결과 확인

  1. 13단계 조건 선택

    연령·지역·소득·주거 등 내 상황을 고릅니다.

    • F01 조건 입력 명세
    • 화면 목록과 이동 흐름

  2. 자격과 조합 계산

    코드가 자격과 중복 수급 제한을 반영해 금액을 계산합니다. 모호한 조건은 확인이 필요하다고 표시합니다.

    • F04 자격 진단
    • F05 조합 계산

  3. 비교하고 신청 준비

    조합 총액·근거·상황 변화·정책 상세를 보고 공식 신청처를 확인합니다. AI 설명은 선택적으로 덧붙입니다.

    • F06 상황 변화
    • F07 상세·신청 안내
    • F13 맞춤 설명
