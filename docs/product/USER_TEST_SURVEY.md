# 사용자 테스트 설문조사

> 이 문서는 실사용자 테스트에 쓴 구글 폼 설문의 목적·대상·문항·진행 방법을 기록한다.
> 진행안과 관찰 기록표, 결과 정리는 [사용자 테스트](USER_TEST.md)가 기준이다. 실제 응답 결과와 개선 사항은 USER_TEST.md 5·6장에 정리한다.
> 설문 문항은 USER_TEST.md 3장의 1~23번을 번호 그대로 옮기고, 비대면 테스트용으로 24~26번을 더했다.

## 1. 목적

- [기능 명세](REQUIREMENTS.md) 8.6 성공 기준 중 이해도(설문 1번), 만족도(설문 11번, 다른 서비스 대비 도움 정도), 조건 입력 시간(설문 24번)을 확인한다.
- 실제 배포 사이트를 쓴 사용자가 어디서 헷갈리거나 막히는지 찾고 고칠 곳을 정한다.
- 평가 기준 G5(실사용자 5명 이상 피드백)의 증빙 자료로 쓴다. 테스터 이름·연락처는 공개하지 않는다(G7).

## 4. 테스트 진행 방법

팀원이 아래 안내문과 두 주소를 지인에게 보내고, 참여자가 혼자 진행한다. 진행자가 옆에서 관찰하는 방식이 아니므로 입력 시간과 결과 표시 여부는 설문 24·25번으로 받는다.

1. 서비스 주소에 접속한다.
2. 본인의 조건을 입력하고 추천 결과를 확인한다.
3. 추천된 정책의 상세 내용과 신청 안내를 살펴본다.
4. 사용 후 설문조사에 의견을 남긴다.

폼 첫 화면에 안내한 부탁은 다음과 같다.

1. 처음부터 조건을 골라 결과 화면까지 가 보기
2. 결과 화면에서 기간 바꾸기, [상황이 바뀌면 어떻게 될까?] 눌러 보기
3. 관심 가는 정책 하나를 눌러 신청 페이지까지 가 보기

실제 소득·재산을 고르기 싫으면 비슷한 값을 골라도 된다고 안내했다. 서비스에 고른 조건은 팀이 따로 기록하지 않는다.

## 5. 개인정보 수집 여부

| 항목 | 수집 여부 |
| --- | --- |
| 이름, 연락처 | 수집하지 않음(문항 없음) |
| 이메일 | 수집하지 않음(이메일 수집 꺼 둠) |
| 구글 로그인 | 요구하지 않음 |
| 서비스에 입력한 조건(소득·재산·지역 등) | 설문으로 받지 않음 |
| 나이대, 지금 상황, 지원금 신청 경험 | 선택 응답으로만 받음(18~20번, 통계용) |
| 사용 기기 | 선택 응답(26번) |

참여 동의는 번호 없는 필수 체크 문항으로 받는다.

> 테스트 결과는 팀 GitHub 저장소에 기록되지만 이름과 연락처는 올리지 않고 T1, T2 같은 가명으로만 적어요. 설문 응답은 서비스 개선과 과제 제출에 쓰여요. 결과 화면의 [AI] 표시가 붙은 설명은 AI가 공고 원문을 보고 쓴 거예요.

선택지: 위 내용을 읽었고 참여에 동의해요

응답 원본(구글 폼 응답, CSV)은 저장소에 올리지 않는다. 주관식 응답에 나이·지역·소득 같은 개인 조건이나 식별 가능한 내용이 있으면 지우고, 가명과 요약만 USER_TEST.md에 남긴다. 처리 기준은 USER_TEST.md 6장 '응답 원본'을 따른다.

## 6. 설문 문항과 선택지

5점 척도 선택지: 1 전혀 아니다, 2 아니다, 3 보통, 4 그렇다, 5 매우 그렇다
