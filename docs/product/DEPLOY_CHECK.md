# 배포 사이트 점검 기록

배포된 웹사이트에서 사용자 흐름을 확인하고 정상 동작, 오류, 미확인을 나눠 적는다. 개선 의견은 아직 반영되지 않은 제안이다. 화면 번호와 문구 ID는 [기능 명세](REQUIREMENTS.md) 4장을 따른다. 마지막 장에 기획서·명세서의 기능 목록과 실제 구현을 비교했다.

## 3. 오류와 확인이 필요한 점

### 3.1 1차 점검 오류 (해결됨)

- [내 조합 찾기]를 누르면 진행 단계 표시 없이 바로 실패 화면(문구 L-E1 "지금은 정책 자료를 불러올 수 없어요")이 나왔다. [다시 시도]도 같았다.
- 같은 시각 백엔드 `/health`는 200이었다. 원인은 실제 정책 DB 연동 진행 중으로 안내받았다.
- 2차 점검에서 같은 조건으로 분석이 끝까지 진행됐다. 이 오류는 해결된 것으로 본다.

담당자 확인 전 관찰이다. 원인을 단정하지 않는다.

모두 아직 반영되지 않은 제안이다. 1~3번은 2026-11-15 팀장에게 공유했고 검토하기로 했다. 적용 순서는 11월 17일 테스터용 완성 일정에 맞춰 정한다.
