# 사용자 테스트 진행안과 설문

> 목적: REQUIREMENTS_v2.md 8.6 성공 기준 중 이해도와 만족도, 입력 시간을 확인하고, 고칠 곳을 찾는다.
> 현행 기준: [REQUIREMENTS_v2.md](../REQUIREMENTS_v2.md) v2.3 (취업·주거 MVP·역할 조정·구현 방식 반영), 현행 기획 [PROJECT_PLAN.md](PROJECT_PLAN.md)
> 취업·주거 혜택에 F01~F11과 13단계를 적용해 평가한다. 다른 분류는 확장 대상으로 분리하고 MVP 실패로 세지 않는다.

## 1. 진행 방법

| 항목 | 내용 |
|---|---|
| 대상 | 만 19세부터 39세 청년 5명 이상. 가능하면 취업 준비, 재직, 기혼, 35세 이상이 섞이게 |
| 방식 | 배포된 주소로 본인 휴대폰에서 직접 사용. 진행자는 옆에서 보기만 하고 돕지 않는다 |
| 시간 | 1명당 15분 (사용 5분부터 10분, 설문 5분) |
| 준비물 | 배포 주소, 아래 관찰 기록표, 설문 링크(구글 폼) |
| 진행자 | 현서 (기록 1명 더 있으면 좋음) |

**시작할 때 읽어 주는 말**

> 이 서비스는 받을 수 있는 청년 취업·주거 지원금을 조합해서 보여 주는 서비스예요. 서비스를 평가하는 거라 편하게 진행해 주세요. 실제 소득이나 재산을 고르기 싫으면 비슷한 값을 골라도 괜찮아요. 고른 조건은 저희가 따로 기록하지 않아요.

**기억하기 선택 시 덧붙이는 말**

> 기억하기를 켜면 고른 조건이 이 기기의 브라우저에만 30일 저장되고, 서버에는 저장되지 않아요. 저희 관찰 기록과 브라우저 저장은 분리되어 있어요. 관찰 기록에는 조건 값을 적지 않아요. 끝나고 지우기를 누르면 브라우저 저장값이 바로 지워져요.

**부탁할 일 (순서대로)**

1. 처음부터 조건을 골라 결과까지 가 보기 (F01, F03)
2. 결과 화면에서 왜 이 조합이 1위인지 말로 설명해 보기 (F05)
3. 기간을 2년으로 바꾸고 무엇이 달라졌는지 말해 보기 (F05)
4. 현재가치로 보기를 켜 보고 무슨 뜻인지 말해 보기 (F05)
5. 상황이 바뀌면에서 연 소득이 오르면을 눌러 보고 무슨 뜻인지 말해 보기 (F06)
6. 관심 가는 정책 하나의 신청 페이지까지 가 보기 (F07)
7. 조건 수정으로 값을 바꾸고 결과가 다시 계산되는지 보기 (F01, F04)
8. 기억하기와 결과 이미지 저장을 눌러 보고 저장이 됐는지 보기 (F09, F10)

관심 선택·검색·결과·상황 변화·상세에 취업·주거만 나오는지 확인한다. 가상 계산은 현행 8.3과 `tests/fixtures/mvp_planning_rules.json`을 사용하고 과거 5정책 예시·PNG의 숫자를 수락 기준으로 삼지 않는다. 실제 정책의 확보 수와 정확성은 별도 검수한다.

매일 자동 갱신(F08)과 배포, 사용 상한, 이용 통계(F11)는 테스트 당일 환경 전제로 확인한다. 확인 항목은 4장 결과 정리 양식에 둔다.

## 2. 관찰 기록표 (진행자가 작성)

> 테스트 사용자의 실제 조건(나이, 소득, 재산, 지역 등)은 적지 않는다. 조건 값은 관찰 기록에 남기지 않는 것이 원칙이다.

미구현 기능은 성공처럼 쓰지 않는다. 해당 항목은 통과가 아니라 미구현 또는 보류로 기록하고, 고칠 것 목록에 남긴다.

## 3. 설문 (구글 폼, 사용 직후)

5점 문항: 1 전혀 아니다, 2 아니다, 3 보통, 4 그렇다, 5 매우 그렇다

**A. 이해와 신뢰**

1. 추천 조합이 왜 1위인지 이해됐다
2. 포기하는 지원금이 무슨 뜻인지 이해됐다
3. 현재가치로 보기가 무슨 뜻인지 이해됐다
4. 상황이 바뀌면 화면이 내 상황을 판단하는 데 도움이 됐다
5. 충족과 미충족, 확인 필요 표시가 이해하기 쉬웠다
6. 결과를 믿을 수 있다고 느꼈다 (출처, 근거 문장)

**B. 사용 편의**

7. 질문 수가 적당했다
8. 질문이 이해하기 쉬웠다
9. 분석을 기다리는 시간이 괜찮았다
10. 화면이 보기 편했다

**C. 가치**

11. 온통청년과 보조금24 같은 다른 서비스보다 도움이 됐다
12. 실제로 지원금을 신청할 때 다시 쓰고 싶다
13. 친구에게 추천하고 싶다

**D. 주관식**

14. 가장 좋았던 점
15. 가장 헷갈리거나 불편했던 점
16. 질문 중 대답하기 싫었거나 어려웠던 것 (단계 이름)
17. 이런 기능이 있으면 좋겠다

**E. 기본 정보 (선택)**

18. 나이대: 19부터 24, 25부터 29, 30부터 34, 35부터 39
19. 지금 상황: 학생, 취업 준비, 재직, 기타
20. 정부 지원금을 신청해 본 적: 있다, 없다
