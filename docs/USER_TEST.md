# 사용자 테스트 진행안과 설문 v1.0

> 작성: 이현서 · 2026-10-26
> 추후 진행할 내용
> 목적: REQUIREMENTS 8.6 성공 기준 중 이해도·만족도·입력 시간을 확인하고, 고칠 곳을 찾는다.

## 1. 진행 방법

| 항목 | 내용 |
| --- | --- |
| 대상 | 만 19 ~ 39세 청년 5명 이상 (팀 계획 기준). 가능하면 취업 준비, 재직, 기혼, 35세 이상이 섞이게 |
| 방식 | 배포된 주소로 본인 휴대폰에서 직접 사용. 진행자는 옆에서 보기만 하고 돕지 않는다 |
| 시간 | 1명당 15분 (사용 5 ~ 10분 + 설문 5분) |
| 준비물 | 배포 주소, 아래 관찰 기록표, 설문 링크(구글 폼) |
| 진행자 | 현서 (기록 1명 더 있으면 좋음) |

**시작할 때 읽어 주는 말**

> 이 서비스는 받을 수 있는 청년 지원금을 조합해서 보여 주는 서비스예요. 서비스를 평가하는 거라 편하게 진행해 주시면 돼요. 실제 소득이나 재산을 고르기 싫으면 비슷한 값을 골라도 괜찮아요. 고른 조건은 저희가 따로 기록하지 않아요.

**부탁할 일 (순서대로)**

1. 처음부터 조건을 골라 결과까지 가 보기
2. 결과 화면에서 "왜 이 조합이 1위인지" 말로 설명해 보기
3. 기간을 '2년'으로 바꾸고 무엇이 달라졌는지 말해 보기
4. '현재가치로 보기'를 켜 보고 무슨 뜻인지 말해 보기
5. '상황이 바뀌면'에서 '연 소득이 오르면'을 눌러 보고 무슨 뜻인지 말해 보기
6. 관심 가는 정책 하나의 신청 페이지까지 가 보기

## 3. 설문 (구글 폼, 사용 직후)

5점 문항: 1 전혀 아니다 · 2 아니다 · 3 보통 · 4 그렇다 · 5 매우 그렇다

**A. 이해와 신뢰**

1. 추천 조합이 왜 1위인지 이해됐다
2. '포기하는 지원금'이 무슨 뜻인지 이해됐다
3. '현재가치로 보기'가 무슨 뜻인지 이해됐다
4. '상황이 바뀌면' 화면이 내 상황을 판단하는 데 도움이 됐다
5. ✓ 충족 / ✕ 미충족 / ? 확인 필요 표시가 이해하기 쉬웠다
6. 결과를 믿을 수 있다고 느꼈다 (출처, 근거 문장)

**B. 사용 편의**

7. 질문 수가 적당했다
8. 질문이 이해하기 쉬웠다
9. 분석을 기다리는 시간이 괜찮았다
10. 화면이 보기 편했다

**C. 가치**

11. 온통청년·보조금24 같은 다른 서비스보다 도움이 됐다
12. 실제로 지원금을 신청할 때 다시 쓰고 싶다
13. 친구에게 추천하고 싶다

**D. 주관식**

14. 가장 좋았던 점
15. 가장 헷갈리거나 불편했던 점
16. 질문 중 대답하기 싫었거나 어려웠던 것 (단계 이름)
17. 이런 기능이 있으면 좋겠다

**E. 기본 정보 (선택)**

18. 나이대: 19 ~ 24 / 25 ~ 29 / 30 ~ 34 / 35 ~ 39
19. 지금 상황: 학생 / 취업 준비 / 재직 / 기타
20. 정부 지원금을 신청해 본 적: 있다 / 없다
