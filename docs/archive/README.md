# 과거 기록

이 디렉터리는 과거 기획과 계산 예시를 보존한다. **현행 구현·계산 정답·기술 선택의 기준으로 사용하지 않는다.** 현재 문서는 [문서 지도](../README.md)에서 찾는다.

| 기록 | 용도 |
|---|---|
| [기획서 v1.1](PROJECT_PLAN_v1.1_ARCHIVE.md) | 초기 제품·역할·기술 검토 내용 |
| [요구명세 v1](REQUIREMENTS_v1_ARCHIVE.md) | 자연어 입력과 Must/Should/Could를 쓰던 이전 명세 |
| [기획 시나리오 v2.1](PLANNING_SCENARIOS_v2.1_ARCHIVE.md) | 취업·주거 한정 전 5개 가상 정책·8개 정답의 원문 |
| [문서 정리 전 기획서 v2.5 전체](PROJECT_PLAN_v2.5_ARCHIVE.md) | 중복 부분을 통합하기 전 본문·변경 이력의 보존본 |
| [문서 정리 전 요구명세 안내 v2.5](REQUIREMENTS_INDEX_v2.5_ARCHIVE.md) | 이전 문서 안내와 구 기능 ID → F01~F11 대응표 |

본문의 당시 경로·기술 후보·기능 범위·구현 상태는 역사 기록이다. 이동에 따라 Markdown 링크만 보정했으며, 과거 링크가 현행 문서를 가리켜도 이 기록 자체가 현행으로 바뀌지는 않는다. 변경 근거를 추적할 때만 선택해서 읽는다.

현행 가상 계산 기준은 [기능 명세 8.3](../product/REQUIREMENTS.md#83-정답이-정해진-테스트-사용자)과 `tests/fixtures/mvp_planning_rules.json`이다. `tests/fixtures/planning_rules.json`은 이전 5정책 회귀 자료이며 현행 MVP 수락 기준과 구분한다. 기존 회귀 검증은 유지한다.
