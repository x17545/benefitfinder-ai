# DB 마이그레이션

DB는 PostgreSQL로 확정했다. `versions/`는 향후 스키마 변경 이력의 자리이며, 마이그레이션 도구·초기 스키마·실행 설정은 아직 없다. 주 담당은 백엔드이며 공통 모델 변경은 관련 담당자와 검토한다.

- 도구 선정 후 변경 이력과 적용·상태 확인·실패 복구 방법을 함께 문서화한다. 실행 명령을 미리 존재하는 것처럼 안내하지 않는다.
- 이미 공유 환경에 적용한 이력을 수정·삭제하지 않고 새 마이그레이션을 추가한다.
- 변경 시 기존 데이터의 변환·제약 조건·잠금·복구 가능성을 검토하고 별도 테스트 PostgreSQL에서 적용과 필요한 읽기·쓰기를 검증한다.
- import나 서버 시작 시 자동 테이블 생성으로 이력을 대신하지 않는다.
- 운영·공유 DB의 데이터 삭제나 스키마 적용은 영향과 권한을 확인한 뒤 승인된 범위에서 수행한다.
- 원본 데이터·DB 덤프·실제 연결 문자열·자격 증명은 저장하지 않는다.
