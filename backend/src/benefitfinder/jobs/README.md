# 작업 실행

현재는 담당 영역을 구분하는 뼈대이며 기능은 구현하지 않았다.

수집·갱신 작업의 실행 진입점과 실패·재실행 제어를 둔다. 수집·정제 로직은 ingestion에 위임한다. 사용자 API 요청과 긴 작업을 분리하고 스케줄러·큐 제품은 필요할 때 정한다.

기획 명세 v2의 매일 03:00 KST 갱신, 기준금리 갱신, 실패 알림을 구현할 자리다. 실패한 실행으로 마지막 성공 시각을 갱신하지 않는다. 공고가 바뀌면 재검수 대상으로 되돌리고, 검수 완료 여부를 조합 계산에 전달한다. 구체 스케줄러·알림 연동은 아직 구현하지 않았다.

자동화 주 담당은 양승현이다(2026-10-28). 실행·스케줄·재시도·실패 알림을 맡고, 윤정찬의 수집·출처·버전 함수와 탁서윤의 Agent 분석·정제 흐름에 연결한다. 김하정은 API·DB·계산 연동을 지원한다. Agent 초안과 검수·게시 결과를 구분하고 미지원·상충·불명확은 검수 대기로 남긴다. 기존 모듈 의존 방향을 유지하며 jobs가 ai 내부를 직접 import하지 않고 조립 지점과 application 인터페이스로 연결한다.
