# 데이터 수집·정제

현재는 담당 영역을 구분하는 뼈대이며 기능은 구현하지 않았다.

출처별 응답 파싱·정규화·중복 처리·품질 검증을 둔다. 결과는 contracts의 공통 혜택 형식을 따른다. 네트워크·저장 어댑터는 주입받고 수집 실행 주기는 jobs가 담당한다. 원본·수집 시점·문서 버전을 보존한다.

윤정찬은 원천 수집·출처·원본 관리를, 탁서윤은 수집 후 분석·조건 구조화·정제·품질 검증을 중심으로 협업한다. 검수된 조건·금액·중복 제한·원문 근거를 백엔드에 넘기고, 실행 함수와 실패·재검수 결과를 양승현의 자동화에 연결한다. 작업은 Issue에서 파일별로 나눈다.
