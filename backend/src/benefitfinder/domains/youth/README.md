# 청년정책 분야

현재는 담당 영역을 구분하는 뼈대이며 기능은 구현하지 않았다.

청년정책 특유의 조건·용어·추가 정보의 의미를 정의한다. 공통 domain을 재사용하고 다른 분야를 참조하지 않는다. [기획 명세 v2](../../../../../REQUIREMENTS_v2.md)의 13단계 선택값을 공통 프로필과 `contracts/v1/youth-profile.schema.json`의 `domain_data`로 매핑한다. 필드명·형식은 개발용 계약 초안이며 기획자와 다음 회의에서 확인한다.

군복무 기간·소득·재산 구간은 상한값으로 확정하지 않는다. 해당 구간 전체가 정책 근거를 충족하거나 실패할 때만 판정하고, 기준선을 가로지르거나 근거가 부족하면 `needs_review`로 남긴다. 부모 정보 입력을 생략하는 화면 규칙과 각 정책의 부모 기준 면제 여부도 구분한다. 정책별 판정 근거·단위·경계값 테스트를 함께 관리한다.
