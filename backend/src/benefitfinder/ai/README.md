# 선택 AI 기능

기존 디렉터리를 보존한 향후 검토 자리이며 현재 전담은 없다. MVP는 구조화된 정책 DB 검색·일반 분석 흐름·판정 코드·근거 템플릿으로 구현한다. RAG·Agent·LLM·임베딩은 필수가 아니며, 도입 목적과 필요성을 먼저 검토한다. 아래 내용은 실제 도입 시의 경계 원칙이다.

현재는 담당 영역을 구분하는 뼈대이며 기능은 구현하지 않았다.

정책 원문 조건의 구조화, Agent 도구 선택, 근거 검색, 설명 생성과 AI 평가를 둔다. 사용자 조건은 기획 명세 v2의 선택값으로 받고, 검색·판정·조합·상황 변화 도구와 LLM은 인터페이스로 주입받는다. DB나 LLM SDK를 직접 사용하지 않고 API 라우터를 호출하지 않는다. 진행 이벤트를 API에 전달하되 SSE 인코딩은 HTTP 경계가 담당한다. 특수 조건·부모님 정보를 도구 결과나 설명으로 우회 전달하지 않는다. 분야별 문구는 해당 분야 모듈과 협의한다.
