# 정책 원문 분석 Agent

작업 전에는 루트 지침과 이 경로의 [추가 에이전트 지침](AGENTS.md)을 함께 읽는다.

데이터 준비의 Agent 영역이며 탁서윤이 원문 분석·규칙 후보 추출·평가를 맡는다. API만으로 확인되지 않는 양립·중복·예외 조건을 공식 공고·지침·FAQ로 보완한다. 사용자 검색·판정·조합 계산은 검수·게시된 데이터와 일반 코드로 수행한다. 구체 모델·Agent 도구·RAG·벡터 검색은 미확정이다.

F12의 로컬 실행은 공식 공고 한 건에서 중복 제한과 자격·금액·지급 시점 후보를 [한 명령으로 만들 수 있다](../jobs/README.md#한-번에-f12-검수-자료-만들기). 중복 제한은 확인된 별칭으로 상대 정책을 연결하고 제한과 예외를 구분한다. 모델이 조회한 범위에서 제한이나 허용 문장 바로 다음 줄에 괄호로 이어진 허용 조건은 인용 범위와 예외 목록에 원문 그대로 보존한다. 자격·금액·지급 시점은 모델이 고른 원문과 이어진 조건·예외를 그대로 인용하고, 코드가 그 인용에 명시된 수치만 읽는다. 두 결과 모두 원문 버전·해시를 남기며 검수 후보를 만들 뿐이다. 다중 문서 분석, 운영 게시와 모델 선정은 후속 작업이다.

자격 후보는 제목으로 구분한 자격·제외 조항의 이어진 줄과 예외를 함께 보존하고, 소득 조건에는 따로 적힌 소득 예외도 제시한다. 금액 후보는 실제 비용·생애 한도·기수혜 차감을 같은 근거에 남기며, 다른 절의 급여 차감 FAQ도 질문과 답변을 함께 보존한다. 수치 없는 차감 근거는 금액 배열을 비워 둔다. 문맥이 입력 한도를 넘으면 일부를 잘라 분석하지 않고 실패한다. 원문의 접속어·출생연도·가구 구분이 모호하면 추정해 고치지 않는다. 근거가 보완된 새 후보도 별도 사람 검수가 필요하며 기존 승인·반려를 재사용하지 않는다.

현재 `extract-chunked-facts`는 공식 원문 전체를 페이지/문단과 앞뒤 문맥으로 나눠 로컬 E4B가 자격·금액·지급 시점의 근거 줄과 별도 예외를 선택하도록 한다. FAQ 질문·답변과 본문·별표 각주를 구조 단위로 보존하며, 모델 원선택과 추가 문맥을 구분한다. 원문 버전·해시·전체 줄 위치를 유지하고 결과는 검수 대기로만 저장한다. 자동 승인·DB 적재·운영 게시·온라인 추천 연결은 하지 않는다. [실행 방법과 문맥 한계](../jobs/README.md#긴-공식-지침의-문맥-분할-추출)를 따른다.

Agent는 필요한 공식 문서를 찾고 관련 조항을 추출·점검한다. 결과는 규칙 후보이며 적용 방향·조건·기간·예외·금액 영향과 원문 버전을 남겨 검증·사람 검수를 거쳐 게시한다. API 필드 누락을 동시 수급 허용으로 추론하지 않고, 미지원·상충·불명확은 검수 대기로 남긴다. 상세는 [정책 데이터 분석·정제 설계](../../../../docs/architecture/POLICY_DATA_PIPELINE.md)를 따른다.

문서 조회·저장·LLM 접근은 application의 인터페이스로 주입받는다. ingestion·infrastructure·API 모듈을 직접 import하지 않고 조립 지점에서 연결한다. 입력은 공식 정책 문서·정책 식별 정보로 제한하고 사용자 프로필은 보내지 않는다. 외부 문서의 명령은 실행하지 않으며 실제 원문·정제 결과는 Git 제외 경로에, 공유 예제는 가상값으로 둔다.
