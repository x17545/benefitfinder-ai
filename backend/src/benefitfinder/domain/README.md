# 공통 업무 모델

현재는 담당 영역을 구분하는 뼈대이며 기능은 구현하지 않았다.

혜택·자격 조건·판정 결과·근거 등 분야 공통 개념과 순수 규칙을 둔다. Python 표준 라이브러리만 사용한다. 청년정책 전용 문구·필드·외부 SDK·DB 모델을 넣지 않는다. 구현 시 외부 교환 형식은 contracts와 맞춘다.

기획 명세 v2의 조합·현금흐름·현재가치·기간을 맞춘 지원금 변화 비교를 구현 대상으로 한다. 복무기간 등 불확실한 구간은 분야별 규칙이 비교한 결과를 `needs_review`로 보존한다. 안전한 탐색으로 전체 후보의 최적성을 확인하고 자원 한도 초과는 명시적인 실패로 반환한다. 기획용 가상 정답 참조 테스트와 실제 제품 계산기의 검증을 구분한다.
